# ASKA Branding Guidelines

**APPLIES TO: ENTIRE PROJECT (all files, not just portal)**

## What is ASKA?

**ASKA** = **A**gen **S**ekolah **K**ita **A**I

It is the brand name for the AI/smart features across the entire application.

## Usage Rules

1. **Always use "ASKA"** instead of "AI" when referring to smart/automated features
2. **Capitalize correctly**: ASKA (all caps) not "Aska" or "aska"
3. **Full meaning**: "Agen AI Sekolah Kita"

## Where ASKA is Used

- Sidak Route Planner → "ASKA Sidak Route Planner"
- Chat assistant → "Chat dengan ASKA"
- Any automated analysis → "ASKA sedang menganalisis..."
- Loading states → "ASKA sedang memproses..."

## Examples

❌ "AI akan mengoptimalkan rute"
✅ "ASKA akan mengoptimalkan rute"

❌ "AI sedang menganalisis"  
✅ "ASKA sedang menganalisis"

❌ "Powered by AI"
✅ "Didukung oleh ASKA"
