## Implikasi untuk Sistem

### Tipe Tim yang Perlu Didukung:
1. **Tim per Kasi (Jenjang)**: PAUD PMPK, SD, SMP SMA, SMK KP
2. **Tim per Kecamatan (Kasatlak)**: Cilincing, Koja, Kelapa Gading

### Perbedaan Utama:
- **Tim Kasi**: Monitor sekolah berdasarkan JENJANG (semua SD di seluruh wilayah)
- **Tim Kasatlak**: Monitor sekolah berdasarkan LOKASI (semua jenjang di 1 kecamatan)

### User Membership:
- Satu user HANYA di satu tim (tidak bisa rangkap)
- Staf Seksi → Tim Kasi
- Staf Satlak → Tim Kecamatan
- Penilik/Pengawas → Tim Kasi (PAUD)
