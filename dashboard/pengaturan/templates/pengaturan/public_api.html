Dokumentasi Penggunaan Public API (Instansi)
1. Endpoint Data Sekolah

Mengambil daftar seluruh sekolah aktif (SD, SMP, SMA, SMK) beserta NPSN, alamat, dan nomor kontak.

GET {{ request.host_url.rstrip('/') }}/api/v1/public/schools
2. Autentikasi API Key

Sertakan header X-API-Key atau query parameter ?api_key= pada setiap HTTP request:

HTTP Header:
X-API-Key: pk_live_xxxxxxxxxxxxxxxxxxxxxxxx

Atau Query Parameter:
GET {{ request.host_url.rstrip('/') }}/api/v1/public/schools?api_key=pk_live_xxx
